# HFT project

This project is a simple C++ implementation of a Limit Order Book (LOB) for high-frequency trading (HFT) applications. The LOB is a data structure that maintains the list of buy and sell orders for a particular financial instrument, allowing traders to see the current market depth and make informed trading decisions.
